## Sumário Executivo

A **Agadê** é um projeto de marca de óculos (armações impressas em 3D com PET-G reciclado) idealizado por Higor Dornelas, unindo economia circular, manufatura aditiva e alta-costura. O nome nasce da fusão visual das iniciais "HD" (Higor Dornelas / High Definition), que se "derretem" — referência à estática de TVs antigas — até formar a tipografia fluida "Agadê".

* **Proposta de valor:** *“Muito além de óculos com história. Uma cadeia de produção circular movida pelos próprios clientes.”*
* **Visão de longo prazo (North Star):** ser “a Havaianas dos óculos” — um produto hiper-democrático e culturalmente brasileiro.
